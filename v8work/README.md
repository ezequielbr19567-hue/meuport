# Portfólio Roblox Studio — V8

Versão final limpa do portfólio Builder + Luau.

## Ajustes desta versão

- Remove a linha pública de disponibilidade/comissões do hero.
- Remove textos explicativos e mensagens vazias desnecessárias.
- A seção Builder passa a se chamar **Builds / Construções**.
- A seção de programação permanece apenas como **Systems / Sistemas**.
- Remove os kickers públicos `BUILDER SHOWCASE`, `PROGRAMMING/PROGRAMAÇÃO`, `PRICING/VALORES` e `REVIEWS/AVALIAÇÕES` dessas seções.
- O bloco de avaliações no topo fica minimalista: número da média (quando existir) + uma única palavra `Reviews / Avaliações`.
- Mantém sistema EN/PT, avaliações, moderação, upload por arquivo, Supabase, contador e `/dev`.

Não é necessário executar SQL novo nem alterar variáveis da Vercel.
